## 2. 核心需求（Core Requirement）

用户指定七大语音模块之一，本技能自动输出该模块完整的标准化产品需求文档。文档须覆盖功能定义、量化性能指标、上下游接口规范、异常处理策略、可执行验收标准，无需用户二次补充。

### 测试工况统一约定（参考海外公版端到端响应规范）

> 本 SOR 所有性能指标若未单独标注场景，默认按以下统一工况测试。供应商不得擅自更换更宽松条件复测。

| 项目 | 设定值 |
|------|--------|
| 机器人本体状态 | 静止站立（关节微动作可接受） |
| 麦克风处环境噪声 | 45-50 dBA |
| 麦克风处语音声压 | 65-75 dBA |
| 说话人距离 | 1 m（基线） |
| 语速 | 220-300 词/min |
| 语言 | 中文（一期）；中英文混读单独验收 |
| 内存占用率 | 60%-80% |
| **VAD pause time** | 300 ms（国内项目设定；端到端响应比海外 500 ms 设置多约 200 ms） |

**运动场景补充工况**（仅 §2.3 §2.4 中标"运动状态"行使用）：
机器人步行 ≤ 1 m/s，关节电机噪声叠加在 45-50 dBA 环境底噪上，其他参数同上。

### 指标来源说明（Rationale Sources）

> 本 SOR 所有数值指标的依据可溯源到以下 4 大类。每个模块表下方的"指标依据"段会逐项标注来源代号 [S1]~[S4]。

| 代号 | 来源类别 | 具体内容 |

### 2.1 纯声学前端

| 子功能 | 指标 | shall | should | 测试条件 |
|--------|------|-------|--------|----------|
| 回声消除 AEC | 回声抑制量 ERLE | ≥ 30 dB | ≥ 35 dB | TTS 播放 90 dBSPL，1 m 距离，机器人静止 |
| 回声消除 AEC | 残余回声电平 | ≤ -38 dBFS | ≤ -42 dBFS | 同上 |
| 噪声抑制 NS | SNR 改善量 | ≥ 10 dB | ≥ 12 dB | §2 统一工况，65 dBA 语音叠加 50 dBA 噪声 |
| 噪声抑制 NS | 语音失真 DMOS | ≤ 0.5 分 | ≤ 0.3 分 | 5 分制对参考语音盲测 |
| 噪声抑制 NS | 结构噪声抑制（电机/关节） | ≥ 12 dB | ≥ 18 dB | 墨甲电机全速运转，麦距 30 cm（评测基准；实机按实际安装距离复测，按 6 dB/倍距折算） |
| 自动增益 AGC | 输出电平 | -26 dBFS ± 3 dB | -26 dBFS ± 2 dB | 30 cm – 3 m 范围说话人，正常音量 |
| 波束成形（6 阵元圆阵） | 主瓣增益 | ≥ 6 dB | ≥ 7 dB | 目标 0°，旁瓣 90°，远场弥散噪声 |
| 波束成形（4 阵元线阵，降级硬件） | 主瓣增益 | ≥ 4 dB | ≥ 5 dB | 同上；4 元理论上限 6 dB，工程留余量 |
| 处理时延 | 算法总延迟 | ≤ 30 ms | ≤ 22 ms | 16 kHz 单帧处理，ARM Cortex-A78 单核 |

**指标依据**
- AEC ERLE ≥ 30 dB：**[S1]** ITU-T G.168 中等量级回声消除标准；**[S2]** 讯飞 32-38 dB / 思必驰车机 28-32 dB（边缘） / 声智 35-42 dB
- 残余回声 shall ≤ -38 dBFS：**[S2]** 思必驰车机 AEC 实测 -38~-42 dBFS；讯飞顶配 -42~-48 dBFS 为 should
- NS SNR 改善 ≥ 10 dB：**[S1]** ITU-T P.835；**[S2]** 思必驰 10-12 dB / 讯飞 12-15 dB
- 结构噪声抑制 shall ≥ 12 dB / should ≥ 18 dB：**[S2]** 思必驰主要在车载，机器人项目案例少（10-15 dB）；讯飞/声智机器人客户案例 18-25 dB；**[S4]** 关节电机谐波集中在 200-2000 Hz，可用窄带 NS 重点抑制
- AGC -26 dBFS：**[S1]** 移动设备语音上传通用归一化目标（YouTube / WebRTC / Microsoft Speech 一致）
- 波束成形 shall 6 dB / should 7 dB（6 元）：**[S4]** 远场弥散噪声下阵列增益理论上限 = 10·log₁₀(N)，6 元 7.8 dB / 4 元 6.0 dB；**[S2]** 讯飞 6.5-7.5 dB / 思必驰 5.5-6.5 dB / 声智 6.5-7.8 dB
- 处理时延 shall ≤ 30 ms / should ≤ 22 ms：**[S4]** 16 kHz 双帧缓冲 + ARM A78 单核 NS+AEC 实测；**[S2]** 思必驰 22-28 ms / 讯飞 18-25 ms

### 2.2 多模态前端

| 子功能 | 指标 | shall | should | 测试条件 |
|--------|------|-------|--------|----------|
| 声源定向 DOA | 方位角误差 P90 | ≤ 15° | ≤ 10° | 水平 ±90° 范围，1-3 m，§2 统一工况 |
| 目标说话人选择（单人场景） | 正确选择率 | ≥ 88% | ≥ 95% | 单说话人，1-3 m，正面 180° |
| 目标说话人选择（2 人场景） | 正确选择率 | ≥ 82% | ≥ 88% | 2 人同时发言，距离差 ≥ 0.5 m |
| 声视时间对齐 | 时间戳对齐精度 | ≤ 40 ms | ≤ 20 ms | 视觉 30 fps，声学 16 kHz；should 需硬件 PTP |
| 跟踪切换 | 说话人移动后重新锁定时间 | ≤ 200 ms | ≤ 150 ms | 说话人以 1 m/s 横向移动 |
| 处理时延 | 算法总延迟 | ≤ 50 ms | ≤ 35 ms | 与 §6 时延预算表对齐 |

**指标依据**
- DOA 方位角 ≤ 15°：**[S2]** 6 阵元圆阵商用 DOA 方案（声智/讯飞）实测 P90 10-15°
- 目标说话人正确选择率 shall 单人 88% / 2 人 82%：**[S2]** 思必驰机器人多模态较弱（单人 88-92% / 2 人 80-85%）；should 95%/88% 对齐讯飞 + 猎户星空机器人 + 字节豆包多模态客户案例
- 声视时间对齐 ≤ 40 ms：**[S4]** 视觉 30 fps 单帧周期 33.3 ms，纯软件时间戳同步可达一帧量级；硬件 PTP 可至 ≤ 20 ms（should，一期不强制）
- 跟踪切换 ≤ 200 ms：**[S1]** 视觉跟踪 + 声学跟踪联合切换的人因感知阈值（用户感知"无延迟"上限约 250 ms）
- 处理时延 ≤ 50 ms：**[S4]** ARM A78 单核 DOA + 声视融合实测 30-45 ms；**[S3]** 海外公版预算分配

- WRR shall 95%/88%/80% / should 98%/93%/88%：**[S2]** 思必驰 95-97%/86-90%/78-83%（边缘可达）；讯飞 97-99%/92-95%/86-90% 为顶配

### 5.2 性能指标格式规范

所有指标必须严格遵循以下格式，无例外：

```
[指标名称] ≥/≤ [数值] [单位]（[测试场景]，[测试工具/方法]）
```

**合格示例**：
- 字错误率 CER ≤ 5%（§2 统一工况，500 句标准测试集，AISHELL-2 评测脚本）

**不合格示例（禁止出现）**：
- ~~识别准确率较高~~ → 无数值
- ~~延迟 ≤ 200 ms~~ → 无测试条件
- ~~唤醒效果好~~ → 主观描述

| M3 唤醒 | ≤ 50 ms | ≤ 80 ms |
| M4 识别（首字上屏） | ≤ 300 ms | ≤ 450 ms |
| M5 中枢（LLM 路由 + 回填） | ≤ 100 ms | ≤ 100 ms |
| M7 云端 LLM 推理（含 RTT） | ≤ 2000 ms | ≤ 2500 ms |
| M6 TTS 首帧（不含 RTT） | ≤ 200 ms | ≤ 200 ms |
| 云端网络 RTT（TTS 云端时） | ≤ 150 ms | ≤ 150 ms |
| **合计 P95** | **≤ 2880 ms**（目标 ≤ 3500 ms） | **≤ 3560 ms**（目标 ≤ 4000 ms） |

> **首字反馈策略**：LLM 路径下，规则引擎应在 ≤ 800 ms（统一工况）/ ≤ 1200 ms（运动状态）内先返回首字反馈（如「让我想一下」），LLM 真实结果到达后再继续语音输出，避免用户感知 3 秒级"卡顿"。

### 7.6 业务域 / 端到端 / 多语种 指标依据

- 唤醒响应 ≤ 350 ms：**[S3] 海外公版车端项目实测基线**（含播放器延迟 ≤ 50 ms）；**[S2]** 国内主流 250-350 ms
- 本体控制 ≤ 1500 ms：**[S3]** 海外车控 1500 ms 映射；**[S2]** 极氪 1500 / 领克 1300；机器人本体控制（移动/抓取）与车控的 API 调用复杂度同量级
- 信息查询 ≤ 2200 ms：**[S3]** 海外天气 2500 ms 映射回调（机器人本地知识库通常比天气云查询更快）；**[S2]** 极氪天气 1500 / 领克 2000
- 多媒体 ≤ 2200 ms：**[S3]** 海外多媒体 2200 ms 直接对齐；**[S2]** 极氪 2200 / 领克 2300；信源耗时 ≤ 700 ms 为关键瓶颈
- 任务执行 ≤ 2500 ms：**[S3]** 海外地图 2500 ms 映射（多步骤 + 多 API 链场景类似）；**[S2]** 极氪 2100 / 领克 2300；信源耗时 ≤ 800 ms + 一次额外云端交互 200 ms
- 对话闲聊 ≤ 3000 ms (P95)：**[S2]** 讯飞 Spark 4 Turbo / 阿里 Qwen 含 RTT P95 实测 2000 ms；加 ASR 首字上屏 + TTS 首帧 + 中枢路由共 ~1000 ms
- ASR 首字上屏 在线 ≤ 900 / 离线 ≤ 850：**[S3] 海外公版**；国内对标极氪 700 / 领克 650 / 一汽 700；离线少网络传输耗时
- 小语种首字上屏 +200 ms：**[S3] 海外公版 Excel 备注**"研究结论小语种首字延迟比中文多 200 ms"
- 任务成功率 ≥ 92%：**[S2]** 端到端联合概率 = 0.97（ASR）× 0.95（NLU）× 0.99（FC）≈ 0.91；shall 设 92% 略宽于理论下限
- 网络切换 ≤ 500 ms：**[S1]** 4G→Wi-Fi 切换业界标杆（< 1 s 为无感）；**[S2]** 国内车载主流 200-500 ms
