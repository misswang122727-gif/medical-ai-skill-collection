## 2. 核心需求（Core Requirement）

用户指定七大语音模块之一，本技能自动输出该模块完整的标准化产品需求文档。文档须覆盖功能定义、量化性能指标、上下游接口规范、异常处理策略、可执行验收标准，无需用户二次补充。具体指标要求如下。

### 2.1 纯声学前端信号处理——核心指标基线

| 子功能 | 核心指标 | 目标值 | 测试条件 |
|--------|----------|--------|----------|
| 回声消除（AEC） | 回声抑制量（ERLE） | ≥ 30 dB | TTS播放90dBSPL，1m距离，无运动 |
| 回声消除（AEC） | 残余回声电平 | ≤ -40 dBFS | 同上 |
| 噪声抑制（NS） | SNR改善量 | ≥ 10 dB | 工厂噪声底噪65dBSPL叠加人声 |
| 噪声抑制（NS） | 语音失真度（DMOS） | ≤ 0.5 分 | MOS对比参考语音，5分制 |
| 噪声抑制（NS） | 结构噪声抑制（电机/关节） | ≥ 15 dB | 墨甲电机全速运转，麦克风距电机30cm（评测基准距离；实机部署按实际安装距离复测，按6dB/倍距折算） |
| 增益控制（AGC） | 输出电平 | -26 dBFS ± 3 dB | 30cm~3m范围内说话人，正常音量 |
| 波束成形（默认硬件） | 主瓣增益 | ≥ 6 dB（**6阵元圆阵**，与§3.2默认硬件对齐） | 目标方向0°，旁瓣90°，远场弥散噪声 |
| 波束成形（降级硬件） | 主瓣增益 | ≥ 4 dB（**4阵元线阵**，4元理论上限6dB，工程值留余量） | 目标方向0°，旁瓣90°，远场弥散噪声 |
| 整体处理时延 | 算法延迟 | ≤ 30 ms | 16kHz单帧处理，ARM Cortex-A78 |

### 2.2 多模态前端信号处理——核心指标基线

| 子功能 | 核心指标 | 目标值 | 测试条件 |
|--------|----------|--------|----------|
| 声源定向（DOA） | 方位角误差 | ≤ 15°（P90） | 水平±90°范围，1~3m，安静环境 |
| 声视融合锁定 | 说话人正确锁定率 | ≥ 92% | 单说话人，1~3m，正面180° |
| 多人仲裁 | 目标说话人正确选择率 | ≥ 88% | 2人同时发言，距离差≥0.5m |
| 声视时间对齐误差（核心） | 时间戳对齐精度 | ≤ 40 ms | 视觉30fps，声学16kHz，纯软件时间戳同步（1帧周期同量级） |
| 声视时间对齐误差（体验，硬件PTP） | 时间戳对齐精度 | ≤ 20 ms | 要求硬件PTP / IEEE 1588同步或共时钟域采集 |
| 跟踪切换延迟 | 说话人移动后重新锁定时间 | ≤ 200 ms | 说话人以1m/s横向移动 |

### 2.3 唤醒——核心指标基线

| 场景 | 指标 | 目标值 | 测试条件 |
|------|------|--------|----------|
| 安静近场 | 唤醒率（WRR） | ≥ 97% | 1m，0°正面，SNR ≥ 25dB，100次测试 |
| 噪声远场 | 唤醒率（WRR） | ≥ 90% | 3m，±45°，SNR ≥ 5dB，100次测试 |
| 机器人运动中 | 唤醒率（WRR） | ≥ 85% | 步行状态，1m，SNR ≥ 10dB，50次测试 |
| 全天候 | 误唤醒率（FAR） | ≤ 1 次/8h | 典型家庭环境（电视/音乐背景声）持续播放 |
| 端侧部署 | 模型大小 | ≤ 10 MB | 端侧推理，不含语言模型 |
| 功耗 | 唤醒模块待机功耗 | ≤ 0.5 W | NPU独立运行，其余模块休眠 |
| 响应速度（安静） | 唤醒词检测延迟 | ≤ 50 ms | 从唤醒词结束到唤醒事件触发，SNR≥25dB |
| 响应速度（噪声） | 唤醒词检测延迟 | ≤ 80 ms | 从唤醒词结束到唤醒事件触发，SNR≥5dB（与§6预算表对齐） |

### 2.4 识别（ASR）——核心指标基线

| 场景 | 指标 | 目标值 | 测试条件 |
|------|------|--------|----------|
| 安静环境 | 字错误率（CER） | ≤ 5% | 标准500句测试集，SNR ≥ 25dB |
| 噪声环境 | 字错误率（CER） | ≤ 10% | 同测试集，SNR ≥ 5dB，家庭背景噪声 |
| 运动状态 | 字错误率（CER） | ≤ 15% | 墨甲步行，电机噪声叠加，1m距离 |
| 流式识别（安静） | 出文延迟（VAD句末触发→最终结果输出） | ≤ 300 ms | 句长5~20字，SNR≥25dB；"出文延迟"与流式首字延迟为不同指标，避免名实不符 |
| 流式识别（噪声） | 出文延迟（VAD句末触发→最终结果输出） | ≤ 450 ms | 句长5~20字，SNR≥5dB（与§6预算表对齐） |
| 流式首字（体验指标） | 首字上屏延迟（说话开始→首字输出） | ≤ 500 ms | 句长5~20字，SNR≥25dB |
| 热词召回 | 热词识别率 | ≥ 95% | 100条注入热词，每词测试10次 |
| 标点预测 | 句级标点准确率 | ≥ 90% | 200句测试，人工标注对比 |
| 端点检测 | 误切断率 | ≤ 3% | 停顿≤800ms不断句，200句含停顿语料 |

### 2.5 中枢系统——核心指标基线

| 功能 | 指标 | 目标值 | 测试条件 |
|------|------|--------|----------|
| 意图识别 | 五类意图分类准确率 | ≥ 90% | 500条标注测试集（运动/查询/任务/闲聊/无效各100条） |
| 槽位填充 | 实体提取准确率 | ≥ 88% | 同测试集，动作/对象/位置/时间四类槽位 |
| 多轮对话 | 上下文指代消解准确率 | ≥ 85% | 100组多轮对话（≤5轮），含代词/省略 |
| 指令路由 | 规则引擎路由准确率 | ≥ 98% | 200条明确指令（无歧义），规则覆盖范围内 |
| 路由分流（稳态） | 简单指令规则路由覆盖率 | ≥ 80% | 200条明确简单指令稳态分流统计；剩余≤20%进入LLM路径 |
| 降级策略（故障态） | LLM不可用时规则兜底覆盖率 | ≥ 80% | Top 100高频指令集，断网状态测试；与上一行为不同业务态 |
| 处理延迟 | 意图解析+路由下发延迟 | ≤ 100 ms | 文本输入，规则引擎路径 |
| 处理延迟 | LLM路径总延迟（云端） | ≤ 3000 ms（P99） | 含网络RTT≤150ms+云端LLM推理；指令长度≤50字 |
| 安全拦截 | 危险动作指令拦截率 | 100% | 50条预设危险指令测试集（含高速/攻击性动作） |

### 2.6 TTS——核心指标基线

| 功能 | 指标 | 目标值 | 测试条件 |
|------|------|--------|----------|
| 自然度 | 主观音质评分（MOS） | ≥ 4.0 | 盲测，5分制，≥20名听测人，100句测试语料 |
| 流式首帧 | 首音频帧输出延迟（TTFT） | ≤ 200 ms | 句长≤20字，云端合成，**不含网络RTT**（网络RTT单独预算见§6） |
| 完整句延迟 | 20字句完整输出时长 | ≤ 500 ms | 同上，不含网络RTT |
| 发音准确率（核心） | 多音字/专有名词正确率 | ≥ 95% | 200句含多音字和墨甲专有名词测试集（含定制词典） |

| 情感适配 | 情感标签正确体现率 | ≥ 85% | 询问/确认/警告/闲聊四类，各25句，盲测打分 |
| 嘴型同步 | 字级时间戳误差 | ≤ 40 ms | 与视觉嘴型驱动模块联调，逐字对比 |

## 5. 输出交付规范（Output Spec）

### 5.1 文档结构

| 章节编号 | 章节名称 | 内容要求 | 禁止项 |
|----------|----------|----------|--------|
| 文档头部 | 模块/版本/日期/作者 | 四字段必须出现，缺项留空但标签保留 | 省略任意字段标签 |
| 一 | 功能定义 | 所有子功能，每条含输入/处理逻辑/输出，表格形式 | 纯文字段落叙述，缺少三要素任一项 |
| 二 | 性能指标 | 核心指标/体验指标/监控指标三级，全部量化，含测试条件 | 无测试条件的裸数字，"较快/较准"等主观词 |
| 三 | 上下游接口 | 上游输入接口和下游输出接口各自独立，含数据类型/格式/时延SLA/异常码 | 缺失任意接口字段，上下游合并描述 |
| 四 | 异常处理 | ≥5类异常，每类含触发条件（量化）/检测方式/处理动作/恢复条件 | 触发条件不量化，"视情况处理"等模糊表述 |
| 五 | 验收标准 | 每条指标对应一条测试用例，含测试方法/通过条件/测试工具 | 无测试工具，无具体通过条件，纯文字描述 |

### 5.2 性能指标格式规范

所有指标必须严格遵循以下格式，无例外：

```
[指标名称] ≥/≤ [数值] [单位]（[测试场景]，[测试工具/方法]）
```

**合格示例：**
- 字错误率（CER）≤ 5%（500句标准测试集，SNR ≥ 25dB，AISHELL-2评测脚本）
- 唤醒率（WRR）≥ 97%（1m，0°正面，安静环境，100次重复测试）
- TTS首帧延迟 ≤ 200ms（句长≤20字，云端合成，Wireshark抓包计时）

**不合格示例（禁止出现）：**
- ~~识别准确率较高~~ → 无数值，不合格
- ~~延迟≤200ms~~ → 无测试条件，不合格
- ~~唤醒效果好~~ → 主观描述，不合格

### 5.3 验收标准格式规范

每条验收标准必须包含四个字段：

| 字段 | 要求 | 示例 |
|------|------|------|
| 验收项 | 对应功能点或指标名称 | 唤醒率（WRR）安静近场 |
| 测试方法 | 可执行步骤，含测试集/工具/环境 | 在消音室1m处朗读唤醒词100次，记录成功次数 |
| 通过条件 | 量化的pass/fail判定 | 成功次数 ≥ 97次 |
| 测试工具 | 具体工具名称或脚本 | 定制化语音评测脚本 + 声级计校准 |

### 5.4 字数与篇幅

| 文档类型 | 字数范围 | 表格行数下限 |
|----------|----------|--------------|
| 单模块PRD | 1500~3000字（含表格内容） | 功能定义≥5行，性能指标≥8行，异常处理≥5行，验收标准≥8行 |

## 6. 全局约束与风控（Constraints）

| 编号 | 约束类型 | 约束内容 | 违反后处理 |
|------|----------|----------|------------|
| C-01 | 范围约束 | 仅处理七大模块范围内的PRD撰写，不跨界到硬件/驱动/算法训练 | 告知边界，拒绝执行超范围部分 |
| C-02 | 数量约束 | 每次执行仅生成一个模块的PRD | 多模块请求时告知限制，询问优先模块 |
| C-03 | 指标约束 | 所有性能指标必须量化，包含数值+单位+测试条件，三者缺一不合格 | 无法量化时填"[待测试集确定，参考建议：XXX]"，不留空，不填"待定" |
| C-04 | 结构约束 | 五章节固定，顺序锁死，任何情况不增删章节、不调整顺序 | 自检阶段强制修正 |
| C-05 | 内容约束 | 禁止主观形容词（快/准/好/优秀/流畅），禁止未经标注的行业经验值 | 自检阶段强制替换为量化表述 |
| C-06 | 安全约束 | 中枢系统和大模型功能模块中，危险动作拦截必须单独列为一条验收标准，通过条件为100%拦截率 | 缺失则自检补入 |
| C-07 | 一致性约束 | 同一指标在功能定义、性能指标、验收标准三章中数值必须一致 | 自检阶段对齐，不一致则以性能指标章节为准 |
| C-08 | 时延预算约束 | 端到端总预算分两条独立通道：**规则路径**安静≤800ms / 噪声≤1200ms；**LLM路径**安静≤3500ms / 噪声≤4000ms（P95，含首字反馈"让我想一下"在内的整体响应） | 生成每个模块时标注该模块在规则/LLM路径中的时延预算占比 |

**端到端时延预算分配表（强制约束）**

**A. 规则路径（简单确定性指令，覆盖率 ≥ 80%）**

| 模块 | 时延预算（安静） | 时延预算（噪声） |
|------|----------------|----------------|
| 声学前端 | ≤ 30 ms | ≤ 30 ms |
| 多模态前端 | ≤ 50 ms | ≤ 50 ms |
| 唤醒 | ≤ 50 ms | ≤ 80 ms |
| 识别（ASR）出文延迟 | ≤ 300 ms | ≤ 450 ms |
| 中枢系统（规则路径） | ≤ 100 ms | ≤ 100 ms |
| TTS首帧（不含云端RTT） | ≤ 200 ms | ≤ 200 ms |
| 云端网络RTT（TTS云端时） | ≤ 150 ms | ≤ 150 ms |
| **合计** | **≤ 880 ms（目标≤800ms，含余量预警）** | **≤ 1060 ms（目标≤1200ms）** |

**B. LLM路径（复杂/模糊指令，覆盖率 ≤ 20%）**

| 模块 | 时延预算（安静） | 时延预算（噪声） |
|------|----------------|----------------|
| 声学前端 | ≤ 30 ms | ≤ 30 ms |
| 多模态前端 | ≤ 50 ms | ≤ 50 ms |
| 唤醒 | ≤ 50 ms | ≤ 80 ms |
| 识别（ASR）出文延迟 | ≤ 300 ms | ≤ 450 ms |
| 中枢系统（LLM路径路由+回填） | ≤ 100 ms | ≤ 100 ms |
| 云端LLM推理（含网络RTT，P95） | ≤ 2000 ms | ≤ 2500 ms |
| TTS首帧（不含云端RTT） | ≤ 200 ms | ≤ 200 ms |
| 云端网络RTT（TTS云端时） | ≤ 150 ms | ≤ 150 ms |
| **合计（P95）** | **≤ 2880 ms（目标≤3500ms）** | **≤ 3560 ms（目标≤4000ms）** |

> **首字反馈策略**：LLM路径下，规则引擎应在 ≤ 800ms（安静）/ ≤ 1200ms（噪声）内先返回首字反馈（如"让我想一下"），LLM真实结果到达后再继续语音输出，避免用户感知到 3 秒级的"卡顿"。

## 7. 异常兜底规范（Exception Spec）

### 7.1 Skill执行层异常

| 异常类型 | 触发条件 | 检测方式 | 唯一处理逻辑 | 恢复条件 |
|----------|----------|----------|--------------|----------|
| 空白输入 | 输入字数 < 5字，无七大模块关键词 | 输入长度检测 + 关键词匹配 | 输出标准追问话术，列出七大模块选项，停止执行，不生成任何内容 | 用户重新输入有效模块名称 |
| 模块名模糊 | 含关联词但无法精确匹配（如"语音输入"） | 模糊语义匹配 | 自动映射最近似模块，文档头部标注"[已映射为：XXX，如有误请纠正]"，继续执行 | 用户确认或纠正映射 |
| 超出范围 | 含硬件/驱动/竞品/算法训练等禁用关键词 | 关键词黑名单匹配 | 告知边界"本技能聚焦墨甲语音软件链路七大模块PRD撰写，[具体超范围内容]不在范围内"，停止执行 | 用户重新输入目标模块 |
| 多模块同时请求 | 含≥2个模块名称且带"同时/全部/一起/都" | 多模块关键词检测 | 告知"每次仅处理一个模块，请告知优先处理哪个"，提供排序选项 | 用户指定单一优先模块 |
| 连续2轮追问无效 | 用户对追问连续2次回应中无有效模块信息 | 追问计数器 | 输出七大模块概览表（含每模块一句功能简介），引导用户从表中选择 | 用户点选具体模块 |

### 7.2 内容生成层异常

| 异常类型 | 触发条件 | 检测方式 | 唯一处理逻辑 |
|----------|----------|----------|--------------|
